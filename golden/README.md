# Golden set provenance

All 14 sentences were written originally for this project in September 2026 and
synthesized locally with macOS `say` (voices Samantha, Daniel, Karen), then
converted to 16 kHz mono WAV with `afconvert`. No third-party audio, no
recordings of real people, no copyrighted text.

Synthetic speech is clean and robotic — real recorded audio with real accents,
noise, and phone-line codecs will always be a harder and better benchmark.
This set exists so the tool works out of the box and CI has a stable corpus.
Categories map to the ways voice agents actually fail: names, spelled-out
letters and codes, numbers, dates and times, acronyms, technical jargon, and
disfluent conversational speech.
