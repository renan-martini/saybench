# LLM Bench Implementation Plan

Spec: docs/specs/2026-09-09-llm-bench-design.md. TDD per task.

1. manifest: LoadPrompts (jsonl: name?, system?, history?, user, category?,
   max_tokens?) with validation. Tests first.
2. provider: ChatPrompt, LLMResult, LLMTarget interface; fake-llm
   (deterministic); FromLLMSpecs with provider prefixes + duplicate
   rejection. Tests first.
3. provider: openaiCompatible SSE client; tests against local mock server
   (TTFT from first content delta, completion at [DONE], usage tokens,
   auth header, error body surfacing).
4. report: ModeLLM; item fields prompt/ttft_ms/completion_ms/output_tokens/
   tokens_per_sec; summary avg/p95 TTFT, avg completion, avg tok/s;
   categories omitted in llm mode. Tests first.
5. runner.RunLLM. Test with fake-llm.
6. CLI `saybench llm`; llm table in printSummary; dashboard llm mode
   (summary columns, TTFT panel, slowest-prompts table; hide WER-specific
   sections). CI smoke: fake-llm run + grep TTFT + html.
7. llm/golden.jsonl (8 fresh prompts, 4 categories). README section with
   real fake-llm output; ROADMAP tick; v0.6.0; full verification; push.
